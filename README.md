# Farbkontraste prüfen

Ein visuelles Werkzeug zum Prüfen und Vergleichen von Farbkombinationen für digitale Oberflächen.

**Live:** [farbtool.moritzvollmer.de](https://farbtool.moritzvollmer.de/)

## Funktionen

- Farben direkt eingeben und vergleichen
- Kontrastverhältnisse nachvollziehbar darstellen
- Kombinationen im Kontext beurteilen
- Verbindung zu weiterführenden Accessibility-Werkzeugen

## Technische Basis

Statisches HTML, JavaScript, SCSS und Vite.

```sh
npm install
npm run dev
npm run build
```
